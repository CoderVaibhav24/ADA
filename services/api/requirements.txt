# ADA API service.
#
# What is NOT here is the point of the split: no torch, no onnxruntime, no
# transformers, no opencv. This process answers browsers, and the heaviest thing
# it does is read a tile out of a COG. Keeping the model stack out of it takes
# several gigabytes off the image and takes the GPU out of the blast radius of
# an HTTP request.

# --- shared ADA packages (installed from the repo, not from an index) ---
# -e ../../libs/python/ada-core
# -e ../../libs/python/ada-platform
# See the note in services/ml-worker/requirements.txt: pip resolves a relative
# path against the working directory, not against this file, so the Dockerfile
# installs them explicitly.
